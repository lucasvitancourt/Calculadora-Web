# 🧮 Calculadora Web

Calculadora simples feita com **HTML, CSS e JavaScript puro**.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

## ✨ Recursos

- Operações básicas: soma, subtração, multiplicação e divisão
- Visor mostra a expressão completa enquanto você digita
- Botão para limpar tudo
- Sem dependências e sem build

## 🚀 Como usar

```bash
git clone https://github.com/lucasvitancourt/Calculadora-Web.git
cd Calculadora-Web
# abra o index.html no navegador
```

## 📁 Estrutura

```
index.html   # layout da calculadora
styles.css   # estilos
script.js    # lógica dos cálculos
```
